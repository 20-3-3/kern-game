# Ассеты и лицензии

Сейчас в игре нет сторонних ассетов: вся геометрия собрана из примитивов Three.js,
текстуры рисуются кодом на canvas, звук и музыка синтезируются через Web Audio API.

Каждый добавленный файл (модель, текстура, звук, шрифт) записывать сюда:
название, автор, ссылка на источник, лицензия (только CC0 и аналоги).

| Файл | Автор | Источник | Лицензия |
|---|---|---|---|
