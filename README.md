# Керн

Браузерная 3D-игра: экшен от третьего лица. Сейчас готов пролог «Ваш заказ у двери» (около 15 минут).
Сценарий — в [`docs/scenario.md`](docs/scenario.md), правила разработки — в [`CLAUDE.md`](CLAUDE.md).

## Как играть

Игра открывается в Google Chrome по ссылке: **https://20-3-3.github.io/kern-game/**
(ссылка заработает, когда в настройках репозитория включён GitHub Pages: Settings → Pages → Source: **GitHub Actions**).

Кликни по экрану, чтобы камера слушалась мыши. Пауза — Esc или P.

| Действие | Клавиши |
|---|---|
| Движение | WASD |
| Камера | мышь |
| Удар (серия из трёх) | ЛКМ |
| Блок / парирование | ПКМ (держать / нажать в момент удара) |
| Рывок | Shift |
| Захват цели | Q или колесо мыши |
| Аккорд (против людей — бросок) | E |
| Последняя нота | R |
| Датчик Ники «Тишина» | F |
| Пропустить реплику | Пробел |

## Что где лежит

- Тексты игры (все реплики, подсказки, пуши) — `src/data/text/`.
- Баланс (урон, тайминги, окна парирования, рост шкал) — `src/data/balance.ts`, `src/data/combat.ts`, босс — `src/data/bosses/druzhinnik.ts`.
- Карта пролога и погоня — `src/data/levels/`.
- Звуки — `src/data/sounds.ts` (сейчас всё синтезируется кодом; файл можно подключить, прописав `file`).
- Концовки — `src/systems/ending.ts` и условия в `src/data/endings.ts`.

## Для разработки

Нужен Node 20+.

```bash
npm ci
npm run dev     # локальный сервер с автообновлением
npm test        # тесты логики (шкалы, концовки, сохранения, ИИ, босс)
npm run build   # сборка в dist/
```

Отладка: `?debug` в адресе показывает FPS и открывает `window.kern` в консоли,
`?beat=ride|brawl|kern|boss|aftermath|home` сразу запускает нужный отрезок пролога.

## На телефоне

Игра подстраивается под экран: на телефоне и планшете появляется экранное управление.
Держите телефон горизонтально: слева — джойстик (появляется там, где коснулись), справа — свайп для камеры
и кнопки «Удар», «Блок», «Рывок», «Цель», «Аккорд»/«Бросок», «Тишина», «Нота» (только в момент обрыва).
Пауза — кнопка Ⅱ в правом верхнем углу.

На iPhone удобнее всего открыть игру с экрана «Домой»: в Safari «Поделиться» → «На экран „Домой“» —
тогда она запускается на весь экран, без адресной строки.
